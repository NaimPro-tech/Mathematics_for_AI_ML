# 🧮 Mathematics for AI & Machine Learning (From Scratch)

Welcome to the **Mathematics for AI & ML** repository! 

This repository is dedicated to building a strong mathematical foundation for Artificial Intelligence and Machine Learning. Instead of relying on high-level libraries (like Scikit-learn, TensorFlow, or PyTorch) to do the heavy lifting, every mathematical concept and algorithm here is implemented **from scratch** (using pure Python and basic NumPy) to understand what happens under the hood.

---

## 🎯 Objectives
* Understand the core mathematical intuition behind ML and Deep Learning algorithms.
* Bridge the gap between theoretical math equations and actual code.
* Build clean, readable, and well-documented implementations from scratch.

---

## 📚 Topics Covered

### 1. Linear Algebra
- [x] Vectors and Matrices (Addition, Multiplication, Transpose, Inverse)
- [x] Dot Product & Cross Product
- [ ] Eigenvalues and Eigenvectors
- [ ] Singular Value Decomposition (SVD)
- [ ] Principal Component Analysis (PCA) from scratch

### 2. Calculus & Optimization
- [x] Derivatives & Partial Derivatives
- [x] Chain Rule (Backpropagation foundation)
- [ ] Gradient Descent (Batch, Stochastic, Mini-Batch)
- [ ] Cost/Loss Functions (MSE, Cross-Entropy)

### 3. Probability & Statistics
- [ ] Mean, Median, Variance, Standard Deviation
- [ ] Probability Distributions (Normal, Binomial, Poisson)
- [ ] Bayes' Theorem & Naive Bayes Classifier from scratch
- [ ] Maximum Likelihood Estimation (MLE)

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** NumPy (for basic array operations), Matplotlib (for visualizations)

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NaimPro-tech/Mathematics_for_AI_ML.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Mathematics_for_AI_ML
   ```
3. **Install dependencies:**
   ```bash
   pip install numpy matplotlib
   ```
